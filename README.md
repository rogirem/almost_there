# Почти рядом / almost_there

Демо для двух человек за столом. Первый создаёт прогулку, второй входит по коду. После подключения начинаются SMS из 2006 года. На точке приходят две короткие реплики с паузами; после отправки собственного ответа игра автоматически продолжает путь.

## Что изменилось

- Переписка занимает почти весь экран, сверху одна строка контакта.
- Нет конверта, подтверждения прибытия, кнопок получения сообщения и перехода после ответа.
- На втором этапе выбирается реальная ветка маршрута.
- Материалы другого человека приходят только в том месте, где он их создал и где сейчас находится читатель. При отсутствии материала звучит обычная реплика.
- До финала объект не занимают одновременно два активных игрока. При занятости переход автоматически ждёт.
- Потеря связи и молчание отображаются в диалоге. Возвращение восстанавливает связь.
- После финиша обоих реальные сообщения выделяются цветом.
- После взаимного согласия доступны общая PNG-карта и полный маршрут второго участника в Яндекс Картах.

Рабочее демо: [открыть приложение](https://piter-fm-progulka.hillydot4.chatgpt.site/). Аккаунт ChatGPT для участия не требуется.

Первый участник создаёт прогулку и передаёт код, второй входит с другого телефона. На одном компьютере используйте разные браузеры или обычное и приватное окна.

Исходный вижн проекта: [docs/vision.pdf](docs/vision.pdf). Подробности текущей механики и проверки: [docs/revision-v3.md](docs/revision-v3.md).

Версия приложения: 3. В репозиторий включены исходники, шрифты, схема базы, миграции и тесты. Локальные базы, фотографии участников, зависимости, собранные файлы и служебные архивы в Git не включаются.

Опубликованное приложение работает на Cloudflare Workers через Sites, с хранилищами D1 и R2. Для работы демо ноутбук не нужен. Локальный запуск использует собственную базу. В `.openai/hosting.json` указан ID текущего опубликованного сайта; для размещения отдельной копии потребуется создать собственный сайт и заменить его ID.

## Запуск

Node.js >=22.13. `npm run install:ci`, затем `npm run build`. Миграции из drizzle/ применяются по порядку к локальной базе, каждый SQL один раз:

`node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_lush_shinobi_shaw.sql`

Аналогично для 0001_big_reavers.sql и 0002_brave_ironclad.sql. `npm run dev -- --hostname 127.0.0.1` запускает локальное приложение. Sites применяет миграции к отдельной опубликованной базе при развёртывании.

Проверка типов: `npx tsc --noEmit`. Полный локальный тест: `node tests/integration-v3.mjs`. Старый tests/integration.mjs оставлен для истории v2 и не используется для v3.

Локальный тест ускоряет таймеры через SQLite только у собственных тестовых участников. Публичный tests/public-v3.mjs проходит игру с обычными временными интервалами и не меняет базу напрямую.

## Основные файлы

- lib/game.ts: реплики, задания, ветки и ссылки на Яндекс Карты.
- lib/game-server.ts: расписание сообщений, снимок чужого материала для места, занятость объекта, сигнал и переходы.
- app/page.tsx: единая переписка, отправка, выбор ветки и финал.
- lib/collage.ts: PNG с мини-картой и цветными рамками.
- docs/revision-v3.md: подробности механики и источники редакторской проверки.

## Технические границы

Данные хранятся в Cloudflare D1, JPEG в R2. Доступ к фото проверяется сервером по комнате и доставке. До двух согласий имя второго человека не раскрывается. Сессия в HttpOnly-cookie действует 7 дней. Очистка cookie удаляет доступ на устройстве; код комнаты не восстанавливает первую сессию на новом телефоне.

Клиент проверяет связь каждые 1,5 секунды при видимой вкладке. После 45 секунд без heartbeat появляется потеря сети, после 3 минут без действий потеря ответа. В закрытый браузер уведомления не отправляются. Сценарий детерминированный, языковая модель в нём не вызывается.

Логическая занятость объектов не гарантирует физического разведения людей по улицам. Для настоящей прогулки требуется разведка маршрута и отдельный режим прибытия. Текущая версия предназначена для показа за столом.
